Publicação de relatório utilizando GitHub Pages. 
O processo inclui a geração e o deployment automatizado de um relatório em ambiente web, garantindo versionamento, 
rastreabilidade e fácil compartilhamento por meio de uma URL pública ou restrita, conforme a configuração do repositório.

Publishing a report using GitHub Pages. The process includes the automated generation and deployment of a report to a web environment, ensuring version control, 
traceability, and easy sharing via a public or restricted URL, depending on the repository configuration.
